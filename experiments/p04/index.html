Experiment guide · 4 / 6

Run the declared plan, then verify the outputs.

  1. Finalize the experiment scope and resource budget. For archived methods, distinguish historical reproduction from a newly proposed experiment.
  2. Use the separately prepared implementation recipe; first smoke-check an unfamiliar loading, update and checkpoint path.
  3. Start formal candidate and control branches from their declared initializations. Keep their budgets and checkpoint rules fixed.
  4. Check terminal job status, actual updates and saved artifacts; then evaluate the fixed checkpoints on matched samples and conditions.
