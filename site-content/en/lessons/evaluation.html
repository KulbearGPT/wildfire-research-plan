Try it yourself

What should you conclude from this model?

Reason through the question and every option

How to reason: Count the outcomes in this hypothetical 1,000-pixel example. Predicting background everywhere gives 999 true negatives and one false negative, but zero true positives. Accuracy is 999/1,000 = 99.9%; fire recall is 0/1 = 0.

  • It is a strong fire detector — not the answer. The apparently impressive number comes entirely from the many background pixels. The model fails on the only fire pixel, so high accuracy is not evidence of a useful fire detector.
  • Its high accuracy hides complete failure to detect fire — correct. This follows from the counts: every positive is missed even though almost every pixel is classified correctly. Class imbalance lets these two statements coexist.

Take away: Inspect misses, false alarms and positive-class metrics together. With no predicted positives, precision has a zero denominator; record the evaluator’s convention instead of treating it as perfect precision.

Moving the display threshold does not change these scores or ranks, so it does not change this AP.

This calculation illustrates non-interpolated AP for a tiny ranked set. For research results, preserve the project evaluator and aggregation population; do not replace it with a different metric implementation.

Thresholded metric formulas

Precision = TP/(TP+FP); recall = TP/(TP+FN); F1 = 2TP/(2TP+FP+FN); IoU = TP/(TP+FP+FN). A zero denominator has no defined ratio; the demo reports “undefined” instead of silently choosing a convention.

Step 4 · Freeze evaluation

Decide how to judge before seeing the test result.

Use training data to fit weights, validation data for the declared selection procedure, and a predeclared reporting/confirmation design for later evaluation.

Try it yourself

The test image scores highest at τ=0.7. May you choose that threshold for the final report?

Reason through the question and every option

How to reason: A decision threshold is part of the prediction procedure. Trying thresholds against test answers and keeping the highest score makes those answers influence the procedure being evaluated.

  • Yes, it maximizes the result — not the answer. The maximum test score is selected partly because it fits that particular test set. Reporting it as an independent evaluation hides this selection and can overstate generalization.
  • No; choose and freeze the rule using the declared validation procedure — correct. Use the declared validation procedure to choose the threshold, freeze it, then apply it to the designated evaluation data. This keeps selection separate from the final assessment.

Take away: Record where and how the threshold was chosen. Repeated validation tuning can also overfit; already inspected historical test years do not become untouched confirmation data by renaming them.

For comparisons, keep target dates, sample identities, masks and preprocessing matched. A mean alone can hide large differences between years or events.

Where the existing project needs extra care

Historical 2022/2023 test years have already been inspected. Evaluating there does not create untouched confirmation data. T1/T5 also differ in features and architecture, so their difference alone does not isolate history length.
