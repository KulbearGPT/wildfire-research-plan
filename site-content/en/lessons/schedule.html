Step 1 · Name the intervention

Cosine-schedule continuation (X22).

The name tells you the intended change: the learning rate decays with a cosine schedule during continuation. The network, starting weights and missingness augmentation stay matched to ordinary ERM.

Same foundation (B3)Matched ERM: constant LRCosine continuation: decaying LR

The experiment asks whether that schedule improves the chosen validation metrics under the same 3,000-update budget. “X22” remains the identifier in historical records.

Try it yourself

What should change between these two runs?

Reason through the question and every option

How to reason: The question is what changes when the continuation uses cosine instead of the ERM learning-rate schedule. Build two branches from the same B3 bytes, then hold the remaining training and evaluation contract fixed.

  • Only the intended learning-rate schedule — correct. This preserves the intended contrast: the specified constant schedule versus the specified cosine schedule. Match data, augmentation, optimizer setup, batch, update budget and checkpoint rule as well as starting weights.
  • Starting checkpoint and learning-rate schedule — not the answer. Changing starting weights changes what the model already learned. Any score difference would mix this history with the schedule effect.
  • Training years and checkpoint selection — not the answer. Changing training years changes available evidence; changing checkpoint selection changes which model is evaluated. Either change prevents attributing the score difference to the schedule alone.

Take away: Write the intended difference before running. A matched single-seed comparison is still a pilot; it does not establish how stable the effect is across seeds.

Done when: you can state the intervention without relying on its experiment number.

Try it yourself

In the positive toy case, which is the schedule-specific comparison?

Reason through the question and every option

How to reason: In the teaching case A = 0.40, B = 0.46 and C = 0.49. Both B and C continue independently from A with the same budget. B represents ordinary continuation; C changes the schedule.

  • C minus A = 0.09 — not the answer. C − A = 0.09 is the total change from the frozen foundation. It includes the continuation recipe, so assigning all 0.09 to cosine credits the schedule for an improvement ordinary continuation also achieved.
  • C minus B = 0.03 — correct. C − B = 0.03 compares the schedule candidate with the matched ERM control. The arithmetic decomposes the total: 0.09 = (B − A) 0.06 + (C − B) 0.03.

Take away: Use C − B for the schedule comparison, and retain A for context. These invented scores illustrate attribution; they are not empirical evidence of a schedule gain.

Report the four conditions, Primary and Block exactly as in the ERM lesson. A Primary gain can coexist with a clean-input regression.

Step 5 · Submit

Make a narrow conclusion, then check variation.

  1. Attach A/B/C artifact identities and the complete per-condition table.
  2. Report C−B separately from C−A.
  3. Describe gains, regressions and the single-seed scope.
  4. Propose matched additional seeds before claiming a stable improvement.

Do not choose the main metric or a weaker control after seeing the results. More favorable historical test numbers do not create independent confirmation.
