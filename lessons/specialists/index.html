Step 1 · Name the methods

Specialize the training distribution.

Your task: Choose the control that tests separate severity specialists.

Mixed-severity block specialist

X14: specialize on block missingness while sampling 25% or 50% severity.

Fixed-severity block specialists

X17: train separate 25% and 50% specialists.

Both belong to the block-specialist family. In the active runner, these use block dropout with probability 1 and fire-history dropout with probability 0; the mixed specialist samples severity while each fixed specialist uses its declared severity.

These names describe interventions, not guaranteed improvements.

Try it yourself

What is the closest control for the fixed-severity design?

Reason through the question and every option

How to reason: The question is whether separate severity specialists help beyond learning one block-specialized model across severities. A useful control must include the shared specialization ingredient while removing the separation being tested.

  • Only a frozen foundation — not the answer. A frozen foundation omits specialist continuation altogether. A gain over it could come from any extra training or block specialization, so it cannot isolate the benefit of splitting severities.
  • The mixed-severity block specialist — correct. The mixed-severity specialist learns both severities in one model. Comparing against it asks whether separate severity models add value beyond this shared block-training approach. Preserve the relevant initialization, evaluation and declared training contracts.

Take away: Report total training cost and routing assumptions too. Two separately trained specialists can use more total updates than one mixed model; matched per-model budgets do not imply matched system cost.

Done when: you can identify the specialization difference and its nearest control.

Step 3 · Count the cost

Two specialists are two training runs.

Your task: Compare specialization benefits with total training cost.

For one history setting and one seed, each continuation uses 3,000 updates. Count the independent models before interpreting the system gain.

Try it yourself

The system matches ERM on clean AP. Does that prove each expert preserves clean performance?

Reason through the question and every option

How to reason: Trace which weights actually produced the clean prediction. The routed system sends complete inputs to ERM, so its clean metric measures that branch, regardless of how well the block specialists work elsewhere.

  • Yes — not the answer. This attributes ERM’s output to specialists that were not used. A specialist could perform poorly on clean inputs while the routed system still looks strong because ERM handles those inputs.
  • No; clean inputs were routed to ERM — correct. The routing decision explains why the system score cannot answer the specialist question. Evaluate each specialist directly on the same clean population to assess its clean performance.

Take away: Separate branch metrics from system metrics. Report which model handled each condition; a routing assumption available in a controlled test is not automatically available during a natural outage.

Done when: you separate training/storage cost, routed inference cost and standalone expert behavior.
