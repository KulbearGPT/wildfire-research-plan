# 三个后续方向：验证记录

状态：执行中，尚未形成正式 AP 结论。此文件对应本会话约定的归一化、静态/动态延迟融合、同缺失输入专家蒸馏。

## 固定实验与判定

- 原始 T1 Res18-U-Net / T5 Res18-UTAE 初始化，训练年 2016–2020，2021 seed 0 完整筛选；每个场景 3181 个样本。
- 学习实验使用相同 AdamW、初始 LR .001、cosine 衰减、3000 更新、物理与有效 batch 64。控制、混合浅层、分组浅层、蒸馏四臂均重新运行匹配对照。
- 归一化：4096 个训练样本，冻结 X22 权重；同一批固定前向激活估计公共统计与块缺失有/无两套统计。两者均不更新梯度、Dropout 或原始 BN 缓冲。先比较公共、条件和原始三种结果；同时超过公共统计和原始 X22，且通过 clean guardrail，才进入独立 BN affine 参数的后续实验。
- 融合：两层 3x3 非线性残差浅层在原主干混合通道前处理输入；typed 分开静态和动态，mixed 混合处理。初始化均为恒等映射，两臂新增参数量完全相同：T1 为 11,520，T5 为 9,504。typed 相对 mixed 的缺失主指标增益在两种设置中均须至少 +.005，并超过原 cosine 控制；M00 相对两种控制均不得下降超过 .010。
- 蒸馏：师生使用同一份缺失后输入；教师按可观测掩码固定选择 ERM / X22 / 25% / 50% 专家，块缺失优先。原预测损失加 .1 Bernoulli KL，全学生训练。两种设置均须超过无蒸馏学生，并距教师主指标不超过 .003；M00 不得比控制下降超过 .010。关注权重存储，不能预先声称推理更快。
- 正向正式筛选需补 seeds 1/2 和冻结的 2022/2023 报告；未通过则停止该配方，不做参数搜索。历史测试年份已经暴露，不能称为全新未见测试。
