Hide inputs without changing the answer

  1. Complete inputs: retain all three input grids.
  2. No fire history: mark the entire Day 3 fire grid unavailable; retain weather and terrain.
  3. 25% dynamic blocks: mark the top-left 2×2 block unavailable in both dynamic grids.
  4. 50% dynamic blocks: mark the left two columns unavailable in both dynamic grids.

Draw unavailable cells as “?”. Keep terrain and the Day 4 target unchanged. These hand-drawn masks illustrate the conditions; they are not the benchmark mask generator or its numerical fill representation.

During training, FireDrop/BlockDrop sample corruptions to teach the model under missing inputs. During evaluation, the named conditions define which inputs are hidden for each fixed checkpoint. Matching conditions requires matching sample and mask identities, not only the percentage hidden.
