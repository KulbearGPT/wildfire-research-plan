Choose what you will complete today

Begin with lessons 1–3. Then follow either the browser study route or the cluster practical route. Both use the same concepts, but produce different evidence.

Browser study

No GPU, account or data download is needed. Inspect the real observation panels and optionally calculate with the small Cedar teaching case, plan the Fold 2 run, then complete missingness, ERM and cosine exercises. Label your deliverable teaching analysis / not executed.

Cluster practical

Complete the readiness check below, run official Fold 2 in lesson 4, then pass the project handover before the T1 ERM and cosine runs. Label a practical complete only when its artifacts exist.

Queue time does not block conceptual lessons. A prepared plan is useful, but does not count as a completed experiment.

Starting weights for project continuationInstructor supplies verified T1 missingness-trained foundation (B3) or agrees to a B3 training budgetCheckpoint, checksum and completion/provenance record

No account, weight bundle or resource allocation is supplied by this website. Ask for the missing item specifically; do not substitute another student's paths.

Words you will meet in the practical

Checkpoint: saved model state. Seed: a recorded random-number initialization. Optimizer update: one parameter update, not one epoch. Smoke run: a short execution check, not a performance result. Artifact: a saved output such as a log, metric file or checkpoint. Normalization statistics: preprocessing values computed from training data.
