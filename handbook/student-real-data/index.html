Read a real patch before interpreting the model.

These are real 2021 WSTS source observations, not the fictional Cedar arrays. Inspect the date, feature and legend before comparing panels. Candidate event records were fixed from the inventory; within each, the first qualifying consecutive-date window was selected for visible fire. These are dataset event records, not necessarily independent fires; the two displayed crops show similar, potentially overlapping structures. They are teaching cases, not a representative performance sample.

All views use a 128×128 center crop, source pixel coordinates and nearest-neighbor display. No geographic basemap or complete fire perimeter is implied.
