01

研究目标与范围

本项目研究卫星观测不完整时的下一日山火蔓延预测。给定过去若干自然日的火情、天气、地形和植被信息，模型输出下一 UTC 自然日窗口内的 VIIRS 活跃火点概率图。该目标是 active-fire proxy，不等同于真实燃烧概率、精确 t+24h 火线位置或最终烧毁范围。

计划仍以 WSTS+ 为主数据集，并保留质量与观测年龄感知的轻量融合模块。可追溯的自然缺失只在有效性、覆盖或 QA 字段能够可靠恢复时报告；其余缺失实验采用预先定义的受控 corruption。TS-SatFire 作为不同标签合同下的跨数据集压力测试，结果单独报告。

计划完成的工作

  • 复现公开基线，并建立事件隔离的跨年份划分；
  • 实现质量与观测时间感知的融合模块；
  • 区分完整观测、可识别的自然缺失和受控缺失三类评测；
  • 完成消融实验、事件级统计和失败案例分析。

不纳入本项目

  • 山火发生概率、长期轨迹和完整生命周期预测；
  • 跨灾种迁移、全球尺度模型和大型基础模型训练；
  • 大规模架构搜索和多套物理模块；
  • 缺少数据依据的实时部署或预警系统结论。

项目周期保持 10 个月，计划使用一张约 24GB 显存 GPU 或同等算力。前 14 天完成字段级数据闸门；第一个月同时完成公开基线复现。若时间戳、QA 或目标有效性无法恢复，研究继续使用原 backbone 和门控思路，但把相应结论限制为受控缺失条件，不扩大为自然缺失或运行式部署结论。

拟解决的问题

现有工作已经涉及缺失模态、时间戳融合、模态感知山火预测和山火部分可观测预测，因此本项目定位为 New Setting + empirical methodology，不能把 gate、mask 或 Δt 本身作为创新点。论文需要说明：在事件隔离、时间外测试和明确的数据可用性合同下，观测年龄与质量信息是否对下一日 active-fire proxy 预测有稳定作用。

实验设计中需要特别处理四个问题。第一，WSTS 与 TS-SatFire 的标签含义不同。第二，最终事件边界、目标日观测、事后更新的天气与复合产品可能造成 future-informed leakage。第三，随机遮挡只能作为 MCAR sanity check，不能替代云、烟和卫星过境造成的结构化缺失。第四，目标日无有效观测不能自动记为 no-fire。

03

研究问题与假设

在事件隔离和严格时间外评测下，显式使用模态有效性、观测年龄与可获得的 QA 信息，能否比普通拼接、填充和均匀融合更可靠地预测下一自然日的 active-fire proxy，同时保持完整观测条件下的性能？
假设 计划检验 什么结果会否定它 处置
H1
质量、有效性和观测年龄门控在预注册缺失条件下优于 concat + mask 等强基线。		 使用相同 backbone、训练预算和 corruption masks，比较 paired event-macro AP；主结果采用 5 个 matched seeds。 配对改善的 95% 置信区间不为正，或只出现在单一缺失率/年份。 简化或删除门控模块。
H2
门控方法在完整观测条件下满足预注册 non-inferiority margin。		 相对同 backbone 完整观测基线计算 paired event-macro AP 差值；margin 仅由训练/验证 pilot 确定。 完整观测性能下降超过 margin。 降低门控复杂度，或仅在缺失触发时启用。
H3
真实 age/QA 提供超过缺失模式本身的信息。		 比较 mask-only、age-only、QA-only、QA + age，并在 year × missing-rate 分层内打乱 age/QA。 真实元数据不优于 shuffled negative control，或无法在 2022–2023 future holdout 复现。 删除机制主张，保留受控缺失 benchmark 结论。

第一个月完成基线方差估计后，确定性能改善的判定标准。该标准和主评估指标应在运行测试集之前固定。

04

数据与预测合同

数据集安排

WSTS+

作为主数据集，用于训练、验证和跨年份测试。正式使用前确认下载许可、字段定义和官方划分。

TS-SatFire

仅作为不同 proxy label 下的跨数据集压力测试，单独训练、评估和解释；不与 WSTS+ 分数合并。

预测时点

主 benchmark 合同是：使用过去自然日窗口中的 WSTS+ 多模态输入，预测下一 UTC 自然日窗口内的 VIIRS active-fire proxy。它不是统一签发时刻下精确 t+24h 的运行式预测。每个字段仍需记录观测时间、可用时间、空间分辨率、缺失含义和预处理版本，以识别可安全使用的变量。
字段类别 允许条件 泄漏风险 审计动作
历史火情图 仅使用时间戳 ≤ t 的观测，并保留探测有效性/缺失信息。 目标日火点混入输入；预处理窗口跨过签发时点。 逐样本断言最大输入时间 ≤ t。
天气 明确区分“签发时可得的天气预报”与“事后观测/重分析”。 用目标时段的真实观测天气训练和测试，却声称现实预报。 数据清单写明产品名、发布延迟和预报时效，并比较预报数据与重分析数据的差异。
静态地形/燃料 只要时间版本不晚于事件，并记录空间重采样方法。 使用事后更新的燃料/烧毁产品。 保存数据版本和获取日期。
QA、云/烟、模态有效性 只有在真实数据包或可追溯原始产品中存在时使用。 把从目标标签反推的“质量”作为输入。 第一周核对字段来源；不可得时不使用该字段。
事件窗口与目标有效性 benchmark 可保留官方 ROI；运行式结论不得依赖完整事件事后边界。target validity 仅用于 loss/evaluation。 用最终 GlobFire/MTBS 边界定义部署窗口；把云烟或无覆盖的目标像素记为 no-fire。 记录 ROI provenance；能恢复 target validity 时将无效像素标为 unknown，否则只声称 detection-proxy 预测。

数据划分与缺失设置

  • 同一火灾事件不得跨训练集、验证集和测试集。
  • 保留 WSTS+ 官方四折结果用于文献可比性；确认性划分固定为 2016–2020 train、2021 validation、2022–2023 untouched test。
  • 自然缺失只在数据提供有效性或 QA 字段时报告，并单独统计缺失率。
  • 随机像素仅作为 MCAR sanity check；主要受控缺失匹配真实缺失比例、连通块形状、连续时长和跨模态共缺失。
  • 超参数、阈值和早停只使用训练集与验证集确定。

前 14 天 Phase 0 数据闸门

  • 确认下载地址、许可、文件完整性与校验和；
  • 核对事件 ID、年份、样本数以及 observation_time / availability_time / validity / QA / target_validity；
  • 审计事件 ROI、GRIDMET 产品版本与 VNP13A1 等复合产品的时间 lineage；
  • 抽样复算 GFS 风向，并验证 WSTS+ 八年 HDF5 转换；
  • 统计正类比例、事件长度、缺失率和年度分布；
  • 保存 data_manifest.csv、split_manifest.csv 与明确的 continue/pivot 决策。
Phase 0 实测结论（2026-08-08）

完整八年审计覆盖 999 个有效事件：2016--2020 训练集 653 个、2021 验证集 156 个、2022--2023 untouched test 190 个。像素加权 NaN 比例为 1.6668%，单事件最大 NaN 比例为 27.6664%。

标签修复结论：新增年份的源 GeoTIFF 正值已经是整数探测小时，原转换却按 HHMM 再除以 100，导致 HDF5 目标错误归零。active-fire repair version 1 已恢复并激活 392 个文件；独立验证器随后核验全部修复文件，另一次结构检查覆盖全部 999 个活动文件。

更正后的目标计数（事件 / 目标日 / 零目标日 / 正目标像素），按年份：2016 为 92 / 2,102 / 886 / 303,648；2017 为 110 / 2,490 / 1,481 / 177,972；2018 为 176 / 3,597 / 1,373 / 381,935；2019 为 74 / 1,351 / 642 / 45,021；2020 为 201 / 4,091 / 1,615 / 670,920；2021 为 156 / 3,961 / 1,332 / 768,324；2022 为 122 / 3,424 / 2,158 / 105,377；2023 为 68 / 2,442 / 1,297 / 167,952。

按冻结划分：train 为 653 / 13,631 / 5,997 / 1,579,496；validation 为 156 / 3,961 / 1,332 / 768,324；test 为 190 / 5,866 / 3,455 / 273,329。

  • 原始 WSTS 的 2018--2021 年共有 607 个有效事件；WSTS+ 新增年份压缩包有 397 个事件目录，其中 5 个 2022 目录为空，最终新增 392 个有效事件。
  • 2018--2021 的 607 个事件均可从 GeoTIFF 恢复有限经纬度；新增年份仅 1/392 个事件保留有限 ROI 坐标。
  • 加强后的目标完整性闸门要求每个现有 benchmark 年份和每个冻结划分都包含非零正目标像素；八个年份和三个划分均通过。
  • 公开字段仍缺少 observation_time、availability_time、qa、coverage 与 target_validity。
  • 当前保留的运行式阻断项恰为 availability_time、event_roi_provenance 与 target_validity。

决策：continue_controlled。 保留 WSTS+、冻结的跨年份划分、原 backbone 和轻量门控路线；主结论限定为预先定义的受控缺失，不主张已刻画自然缺失或具备运行式部署能力。

模型组成

1. 模态编码

每类输入由轻量编码器映射到共同空间尺度，编码器沿用公开基线。

2. 可靠性估计

使用可追溯质量字段、有效性 mask 和观测年龄估计空间相关的模态权重，并比较 scalar、patch 与 pixel gate。

3. 时序融合

从 ConvLSTM、时序卷积或公开基线中选择一种结构。

4. 单任务解码

模型输出下一日概率图，损失函数按类别不平衡情况确定。

门控结构保持为必做模块；若真实 QA 或 acquisition time 不可恢复，则退化为 validity/mask-conditioned gate，并把 observation-age 与自然缺失结论移出主贡献。辅助监督、物理一致性项和大型预训练模型不纳入本周期。

主实验

E1 · 标准完整观测

比较公开基线与拟议方法在固定划分下的性能，并检查完整观测条件下是否退化。

E2 · 缺失与异步压力测试

分别评估完整观测、可识别的自然缺失和匹配真实结构的受控缺失；IID 随机像素只作 MCAR sanity check。

E3 · 跨年份/事件泛化

官方四折用于文献比较；确认性结果使用冻结的 2016–2020 / 2021 / 2022–2023 forward split，并按年份和事件属性分层报告。

E4 · 消融与失败分析

比较 mask-only、age-only、QA-only、QA + age 与 shuffled age/QA negative control；展示真阳性、漏检、误报和错误扩散案例。

实验一致性

  • Pilot 使用 3 个固定种子；主比较使用 5 个 matched seed pairs，并保存逐样本预测。
  • 同类模型使用一致的数据增强、训练轮数/早停、输入历史长度和调参预算。
  • 主结论只使用预先指定的指标和测试划分。
  • 只有数据、划分、预处理和指标一致时，才进行数值对比。
07

评估指标

山火蔓延标签中正类像素较少，因此主指标采用 Average Precision（AP/AUPRC），不以 Accuracy 作为主要结果。

层级 指标 报告方式 备注
主指标 Average Precision / AUPRC 主效应报告 paired Δ event-macro AP；同时给 pooled AP、正类 prevalence 与 persistence AP。 跨年份解释相对同年基线的改善，不直接比较不同 prevalence 下的 raw AP。
空间重叠 IoU、F1、Precision、Recall、FSS 阈值只在验证集冻结；FSS 报告 0、1、2、4 pixel 邻域。 同时评价像素重叠和空间位移容忍尺度。
概率质量 Brier score/skill、ECE、reliability diagram Brier skill 相对同年 climatology 或 persistence；校准仅在验证集拟合。 ECE 仅作诊断，使用等频分箱、bootstrap band 和火区分层。
分层结果 最差年份、缺失强度曲线、事件规模分层 报告均值、分布和样本量。 用于判断结果是否由少数事件或年份驱动。

统计单位

采用 paired、year-stratified、cluster-preserving event bootstrap，整场火灾连同全部日期和像素共同重采样，至少 10,000 次。模型差值必须在相同重采样事件和 matched seeds 上计算；同时报告 equal-event 与 pixel-weighted estimand。

阶段目标与止损条件

第 14 天
目标：完成 acquisition/availability time、validity、QA、target validity、ROI 和产品 lineage 审计，形成字段 manifest 与继续/降级决策。
未完成时：不取消原方法路线；把主实验限定为受控缺失，并删除自然缺失与 operational 主张。
第 3 个月
目标：门控模块在预先指定的缺失条件下，3-seed pilot 优于 concat + mask；完整观测满足预注册 non-inferiority margin。
未完成时：简化模块并复查一次。结果仍不稳定时，停止该方法方向。
第 5 个月
目标：在冻结的 2022–2023 future holdout 保持正向效果，并在第二种 backbone 上重复主要趋势，完成配对事件级置信区间与失败分析。
未完成时：重新评估论文是否仍有独立的评估贡献；若没有，则降低投稿目标。
第 7 个月
目标：固定方法、数据划分、主表和主图，之后只处理错误修复、复现实验和论文写作。
未完成时：缩小实验范围，不再增加新模块。

投稿前应确认结果在 5 个 matched seeds 和关键数据切片上保持一致，事件级统计不由少数大事件主导，所有测试阈值与校准均由 validation 冻结，并对可用性合同的限制做准确表述。

09

时间安排

第 1 个月：Phase 0 数据闸门与基线复现

前 14 天完成字段、ROI、产品 lineage、GFS 风向与八年转换审计；同时建立 manifest，复现 no-fire、persistence、Res18-U-Net 与 UTAE 基线。

第 2 至 3 个月：核心模块

实现 concat + mask、LOCF、uniform fusion 与硬屏蔽 observation-age/validity gate，完成 3-seed pilot 和第一组 matched corruption 实验。

第 4 至 5 个月：主实验与跨年份验证

完成 E1 至 E3、官方四折对比、冻结的 future holdout、第二种 backbone 和 5 个 matched seeds，并执行 10,000 次配对事件 bootstrap。

第 6 个月：跨标签压力测试与补充实验

在 TS-SatFire 上单独训练和评估 progression proxy，不与 WSTS+ 分数合并；若实现成本过高，则优先完成负控制、校准和数据质量分析。

第 7 个月：消融与方法固定

完成 E4、计算成本和预测时点敏感性实验，生成主表和主图，固定方法与数据划分。

第 8 至 9 个月：论文写作与内部审阅

完成论文初稿，核对引用和实验数字，根据内部审阅补充必要实验，并整理代码与复现说明。

第 10 个月：投稿准备

完成最终复现、匿名仓库、格式调整和投稿材料，不再增加新的研究模块。

时间仍围绕原研究问题分配：数据闸门只决定证据强度，不改变 WSTS+ 主数据集、轻量门控方法或十个月论文周期。
