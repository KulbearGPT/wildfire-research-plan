Negative and unrun experiments

What has actually been checked

Fresh-environment qualification passed 260 CPU checks, 91 short-budget GPU cases, a 999-event data audit and historical diagnostic replays.

These checks used new environments and relocated paths on the existing physical cluster. They do not reproduce every historical score at full budget.

Three rules for reading results

  1. The target is a next-day active-fire proxy. It is not a complete fire perimeter. The data audit supports controlled-missingness studies, not general claims about natural missingness or operational performance.
  2. T=1/T=5 is a cross-setting comparison. History length, architecture and features change together. Do not attribute the entire difference to more history.
  3. Historical test years have already been evaluated. Reproducing fixed results is valid; developing new methods requires an explicit confirmation plan rather than relabelling those years as unseen tests.

What to submit after your first experiment

An experiment notebook with the code commit, environment and data versions, split, seed, batch size, training budget, Slurm job ID and exit state, checkpoint and metric paths, and an explanation of differences from the reference.

Pass the smoke check before starting formal training. See Start here for completion criteria and a problem-reporting template.
